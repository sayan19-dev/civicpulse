Civic Pulse - Hyderabad (website files)

Upload the CONTENTS of this folder to your web host (e.g. GitHub Pages).
Before it works you must:
  1. Create the Supabase project + run schema.sql   (see SETUP.md in the backend-setup zip)
  2. Paste your Supabase URL and key into config.js

To try it on your computer: double-click start-site.bat (Windows) or run start-site.sh.
It needs Python installed and opens http://localhost:8000.
